 Advanced Smart Gender Classification System
### نظام ذكاء اصطناعي متطور لتصنيف الجنس من الصور باستخدام التعلم الآلي ومعالجة الرؤية الحاسوبية

---

 نبذة عن المشروع (Project Overview)
يُعد هذا المشروع نظاماً هندسياً متكاملاً يعتمد على تقنيات الذكاء الاصطناعي والرؤية الحاسوبية (Computer Vision) لتصنيف صور الأشخاص بدقة عالية وتحديد ما إذا كانت الصورة تعود لـ (ذكر أم أنثى). تم بناء النموذج وتدريبه باستخدام خوارزميات التعلم الآلي المتقدمة واستخراج الخصائص الجوهرية للصور (مثل HOG و Histogram) لضمان أعلى مستويات الدقة والكفاءة في التنبؤ، مع واجهة تفاعلية ذكية للتشغيل الفوري.

---

 هيكل المشروع الهندسي (Project Directory Structure)

```text
Gender-Classification-Project/
│

│   ├── Train/

│

│   └── gender_classification.ipynb

├── src/                      # الشيفرات البرمجية الأساسية وسكريبتات التنفيذ والتشغيل
│   └── predict.py
│
├── .gitignore                # ملف تجاهل الملفات المؤقتة وملفات النظام
├── requirements.txt          # قائمة المكتبات والتبعيات البرمجية اللازمة
└── README.md                 # ملف التوثيق الرسمي للمشروع
 المتطلبات والمكتبات البرمجية (Requirements)
يعتمد المشروع على بيئة لغة بايثون والمكتبات الهندسية التالية:

opencv-python (معالجة الصور والكاميرا)

scikit-learn (خوارزميات النمذجة والتدريب Machine Learning)

scikit-image (استخراج الميزات الهندسية HOG)

numpy & pandas (معالجة البيانات المصفوفاتية والتحليل الإحصائي)

joblib (حفظ واسترجاع النماذج المدربة)

لتثبيت كافة المتطلبات دفعة واحدة عبر موجه الأوامر، استخدم الأمر الآتي:

Bash
pip install -r requirements.txt
 كيفية تشغيل النظام (How to Run)
استعراض الشيفرات ومراحل التدريب:
يمكنك فتح ملف الـ Jupyter Notebook الموجود في مجلد notebooks للاطلاع على مراحل المعالجة والتدريب واستخراج الخصائص:

Bash
jupyter notebook notebooks/gender_classification.ipynb
تشغيل نظام التنبؤ الذكي:
استخدم ملف التشغيل المباشر الموجود في مجلد src لاختبار النماذج المدربة (final_smart_gender_model.pkl) والتنبؤ بالصور الجديدة بدقة فائقة وفي ثوانٍ معدودة.

 ملاحظة تنظيمية حول البيانات (Dataset Notice)
تم إرفاق عينة تجريبية مصغرة فقط من البيانات داخل مجلد dataset لغرض توضيح بنية المشروع واختبار الأكواد، نظراً للضخامة الهائل لحجم مجموعة البيانات الأصلية وسياسات التخزين على المنصة.
